## File Descriptions

### Main Files
- **main.py**: Entry point for the IAM project.
- **README.md**: Documentation and overview of the project.
- **requirements.txt**: Lists Python dependencies for the project.

### Scripts
- **iam_setup.sh**: Script for setting up the IAM environment.
- **reset_iam_env.sh**: Resets the IAM environment.
- **restart_jupyter.sh**: Restarts Jupyter Notebook.
- **setup_iam_structure.sh**: Sets up the IAM project structure.
- **setup_pybel.sh**: Installs Pybel dependencies.
- **start_iam_notebook.sh**: Starts the IAM notebook.
- **start.sh**: General startup script.

### IAM_GUI
- **backend.py**: Flask backend for the IAM Molecule Viewer.
- **templates/iam_viewer_connected.html**: Main HTML template for the IAM Molecule Viewer.
- **static/script.js**: JavaScript logic for frontend interactions.
- **static/style.css**: Styling for the IAM Molecule Viewer.

### IAM_Knowledge
- **Molecules/methane_test.xyz**: Example molecule file.

### IAM_Molecule_Engine
- **iam_molecule_engine.py**: Core logic for molecule processing.
- **xtb_wrapper.py**: Wrapper for XTB calculations.

### Notebooks
- **IAM_Notebooks/IAM_xtb_pipeline_test.ipynb**: Jupyter notebook for testing the XTB pipeline.

### Tools
- **xtb/xtb.py**: XTB tool script.
- **xtb/xtb_wrapper_test/xtb_wrapper.py**: Test wrapper for XTB.

### WebUI
- **webui/app.py**: Flask application for the web interface.
- **webui/templates/index.html**: HTML template for the web interface.

## Progress Summary
